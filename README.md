# إضافة ترجمة عربية مجمّعة لستريميو (SubDL + SubSource)

إضافة ستريميو تجيب ترجمة عربية من مصدرين مجتمعين: **SubDL** و **SubSource**، وتعرضهم في نفس اضافة واحدة داخل ستريميو.


## التثبيت داخل ستريميو

1. افتح تطبيق ستريميو (أو الويب)
2. روح لصفحة **الإضافات (Addons)**
3. انسخ الرابط `https://arabic-subtitle-stremio.lovable.app/api/public/manifest.json` وحطه في خانة "Addon Repository URL" فوق
4. اضغط إنتر، وثبت الإضافة

بعدها، أي فيلم أو حلقة مسلسل تفتحها في ستريميو، رح تلاقي ترجمة الإضافة موجودة
