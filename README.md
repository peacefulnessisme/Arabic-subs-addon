# إضافة ترجمة عربية مجمّعة لستريميو (SubDL + SubSource)

إضافة ستريميو تجيب ترجمة عربية من مصدرين مجتمعين: **SubDL** و **SubSource**، وتعرضهم في نفس قائمة الترجمة داخل ستريميو.

⚠️ **ملاحظة مهمة**: SubSource ما عندها بحث مباشر بـ IMDB ID في الـ API الرسمي، فالإضافة تجيب اسم العمل أول عن طريق Cinemeta (بيانات ستريميو الرسمية) وتبحث فيه بالاسم. لو صار تغيير بسيط بشكل استجابة SubSource API مستقبلاً، قد تحتاج تعدّل أسماء الحقول بملف `providers/subsource.js` (موضحة بالتعليقات داخل الكود).

## المتطلبات

- Node.js نسخة 16 أو أحدث
- مفتاح API من SubDL (مجاني): https://subdl.com/panel/api
- مفتاح API من SubSource (مجاني): سجل حساب في subsource.net ثم روح لصفحة "My Profile"

## التثبيت والتشغيل

```bash
# 1. فك ضغط المجلد ثم ادخل عليه
cd arabic-subs-addon

# 2. ثبت المكتبات
npm install

# 3. جهز ملف الإعدادات
cp .env.example .env
```

افتح ملف `.env` وحط مفاتيح الـ API اللي جبتها:

```
SUBDL_API_KEY=المفتاح_تبعك
SUBSOURCE_API_KEY=المفتاح_تبعك
```

```bash
# 4. شغل السيرفر
npm start
```

بيطلع لك رسالة فيها رابط شبيه بـ:

```
http://127.0.0.1:7000/manifest.json
```

## التثبيت داخل ستريميو

1. افتح تطبيق ستريميو (أو الويب)
2. روح لصفحة **الإضافات (Addons)**
3. انسخ الرابط `http://127.0.0.1:7000/manifest.json` وحطه في خانة "Addon Repository URL" فوق
4. اضغط إنتر، وثبت الإضافة

بعدها، أي فيلم أو حلقة مسلسل تفتحها في ستريميو، رح تلقى خيارات ترجمة عربية من SubDL و SubSource مع بعض بقائمة الترجمة.

## تجربة Better Call Saul (المواسم 1-6)

الإضافة تشتغل تلقائي مع أي مسلسل عندك بالـ IMDB ID، بدون أي إعداد إضافي. لما تفتح أي حلقة من Better Call Saul (أي موسم من 1 إلى 6) من مصدر الفيديو تبعك بستريميو، الإضافة بتحاول تجيب لها ترجمة عربية من كل مصدر تلقائياً حسب رقم الموسم والحلقة.

## استضافة دائمة (اختياري)

إذا ما تبي تشغل السيرفر على جهازك كل مرة، تقدر ترفع نفس الكود على خدمة استضافة مجانية زي Render أو Railway أو Vercel (تحتاج تعديل بسيط للتوافق مع serverless حسب المنصة)، وتحط متغيرات البيئة (`SUBDL_API_KEY`, `SUBSOURCE_API_KEY`) من لوحة تحكم الخدمة بدل ملف `.env`.

## استكشاف الأخطاء

- إذا ما طلعت ترجمة أبداً: تأكد إن مفاتيح الـ API صحيحة وشغالة (جرب تسجل دخول بحسابك بموقع SubDL/SubSource وتتأكد المفتاح فعّال)
- شوف رسائل الـ console وقت تشغيل `npm start` - الإضافة تطبع تفاصيل كل طلب وأي خطأ يصير
